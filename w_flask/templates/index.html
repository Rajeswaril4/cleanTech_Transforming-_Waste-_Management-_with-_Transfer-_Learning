How It Works

This system uses a trained deep learning model based on VGG16 to classify municipal waste images into three categories:

  • Biodegradable
  • Recyclable
  • Trash

The AI model was trained on a labeled dataset of waste images. When you upload an image, the system processes it and returns a classification result based on the trained model's prediction.
